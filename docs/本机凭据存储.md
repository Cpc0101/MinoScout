# Scout 本机插件凭据存储

插件密钥只保存在 Scout 自己的用户私有目录，不使用操作系统凭据服务。

## 存储位置

- 未归属历史目录：`<config_dir>/plugin-secrets`
- 已确认账号归属：`<config_dir>/accounts/<profile>/plugin-secrets`
- 密钥文件按完整账号名做 SHA-256 后分别保存，不把邮箱、字段名或值写进文件名。
- 值使用 JSON 明文保存；这是文件权限保护的本机配置，不是加密保险箱。

## 权限与并发

- 目录固定为 `0700`，文件和锁文件固定为 `0600`。
- POSIX 平台拒绝符号链接、多人所有、硬链接和权限不符的文件。
- 写入先在同目录创建独占临时文件，执行 `fsync` 后原子替换目标文件。
- 同一账号的读写使用进程锁，避免 Scout 主进程与更新助手并发覆盖。
- Windows 使用同样的目录隔离、用户配置文件权限和 `msvcrt` 进程锁。

## 账号隔离

插件状态目录和密钥目录都从同一 profile 派生。Nexus 确认账号归属后，不同 Nexus 服务或用户使用不同 profile；冲突账号不会读取或继承另一账号的密钥。

## 迁移边界

- 飞书 CLI 等工具自己的配置继续留在其账号目录，不复制到 Scout 的统一密钥文件。
- Nexus 业务测试账号仍只由 Nexus 号池管理；Scout 不保存号池密码。
- 配置导出仍会携带明文凭据，只用于用户显式发起的迁移，响应不得进入持久日志。
